# Spot Saver

Build a single-page, mobile-first, high-converting ₹3 community access landing page funnel inspired by creator coaching workshops.

Key requirements:
- Clean, bold, high-contrast coaching funnel design with a white/light theme and a strong warm accent (vibrant orange/red) for CTAs, badges, and prices. Rounded cards, soft shadows, bold sans-serif typography. No navbar or distraction menus.
- Mobile-first optimization with a persistent sticky mobile bottom bar showing current price (struck-through original + ₹3), seats-left countdown, and CTA button.
- Hero Section: community member avatar collage, punchy transformation headline and subhead, live cohort/session chips, YouTube embed placeholder (rel=0&modestbranding=1), primary "Lock My Spot @ ₹3" CTA, and a 3-stat animated count-up strip.
- Testimonial Screenshot Grid: "Real People. Real Results" with 5 chat/DM/review-style cards (responsive masonry/horizontal scroll on mobile).
- What's Inside: numbered expandable/stacked cards with curriculum bullets, repeated CTA, and secure checkout microcopy.
- Who This Is For: 2x2 mobile / 4-column desktop grid with photos and audience labels (Students, Freshers, Creators, Personal Brands).
- Value Stack / Price Reveal: 3 bonus cards with struck-through values, total value vs. ₹3 today, and "You Save ₹X" badge.
- Meet the Mentor: photo, credibility tags, origin story bio, 3-stat strip, pull-quote, and before/after contrast list.
- As Featured On: logo marquee strip.
- Scarcity / Availability Block: seats-filled progress bar (e.g., 156/200 filled), urgency highlights, and repeat CTA.
- What Happens Next: numbered 5-step registration-to-access onboarding walkthrough.
- FAQ: 5-item accordion for common objections.
- Registration / Checkout Section: clean lead form (Full Name, Email, 10-digit WhatsApp Number validation, Terms checkbox) with CTA and trust badges (Secure Payment, Instant WhatsApp confirmation, limited spots).
- UTM/fbclid query parameter preservation on page load, and clearly commented placeholder snippets for Meta Pixel and Google Tag Manager.
